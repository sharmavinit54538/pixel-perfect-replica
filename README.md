# Property Connect UI

Build a clean, modern frontend UI for an AI Voice Calling Assistant for a real-estate/builder company.

Only frontend UI. Do NOT create, modify, or connect any backend, API, database, authentication, Twilio, Asterisk, GSM Gateway, or AI logic.

Pages:

1. Dashboard

- Total Calls

- Answered

- Interested

- Not Interested

- Follow-ups

- Call duration/cost summary

- Recent calls table

2. Projects

- Project cards with name, location, price, configuration, status

- Add/Edit project UI

- Search and filters

3. AI Call Agent

- Agent name/status

- Greeting/message editor

- Conversation flow preview

- Language selector

- Voice selector

- Enable/Disable toggle

- "Test Call" button (UI only)

4. Calls

- Calls table: customer, number, project, status, duration, date/time

- Status badges: Interested, Not Interested, Follow-up, Completed

- Call details drawer with transcript UI

5. Leads/CRM

- Lead list

- Name, phone, project, interest, budget, status

- Lead details panel

- Follow-up date/time UI

6. Settings

- Twilio configuration UI (frontend only, no real integration)

- Calling number display

- Agent settings

- Notifications

Design:

- Professional SaaS dashboard

- Minimal, premium real-estate style

- Responsive desktop/mobile

- Sidebar navigation + top header

- Cards, tables, badges, modals/drawers

- Use realistic dummy data

- Reusable components

- Keep UI simple and uncluttered

IMPORTANT:

Do not implement backend or real functionality. Use mock/static data only.
